## homepage-catalog-v1.html

Homepage version **e-commerce mobilier style Kave Home**, livrée en S2 avant
que la position réelle de l'atelier soit confirmée (architecture d'intérieur,
pas catalogue de meubles).

Structure : Header · Hero par ambiance · Moodboards 3 · Catégories mobilier 4
(Salon/Chambre/Salle à manger/Bureau) · Atelier split · Journal · Instagram ·
CTA · Footer.

**Réutiliser cette variante si :**
- Coulibaly confirme au RDV vouloir un axe boutique en ligne des pièces mobilier
- L'atelier lance une gamme signature (Tabouret Multifaces + suite) avec vente directe
- Il faut prototyper rapidement un catalogue produit pour un événement (foire, salon)

Les composants CSS mobilisés (`.mood-card`, `.category-card`, `.mood-grid`,
`.category-grid`) sont **conservés dans `src/components/section.css`** et
restent disponibles sans modification.
